# Every version here is pinned exactly, and that is deliberate.
#
# These files used to name packages without versions, so `docker compose
# build` installed whatever was current that day. That is not a build, it is
# a lottery: an unrelated rebuild silently moved the media plane's real-time
# framework from pipecat 1.8.1 to 1.10.0 mid-session, under a live call path,
# with nobody having read a changelog. Two images built from the same commit
# a week apart were not the same image.
#
# So: no `>=`, no bare names. To move a version, change it here, rebuild,
# run that app's suite, and - for anything the audio path touches - make a
# real test call. An upgrade is a commit with evidence behind it, never a
# side effect of rebuilding for something else.
#
# These are the *declared* dependencies. Their own transitive dependencies
# are still resolved at build time; a full lock file is the next step if
# that turns out to matter.
#
# apps/worker runs no jobs yet (CLAUDE.md section 4): the background work
# that exists today runs as FastAPI background tasks inside apps/api. These
# two are what the placeholder process imports.
